# Vendored themes

`TokyoNight Storm` is an unmodified copy of the Ghostty theme used by this
repo's `ghostty/config`, copied from the installed Ghostty bundle on 2026-10-30.
It matches the [iTerm2-Color-Schemes Ghostty export](https://github.com/mbadolato/iTerm2-Color-Schemes/blob/master/ghostty/TokyoNight%20Storm).

The original [Tokyo Night theme](https://github.com/enkia/tokyo-night-vscode-theme)
is by Enkia. The theme and collection license notices are included alongside it.

Rex imports this file directly; no Ghostty installation is required. Importing
copies the colors into that Rex app's settings. Changes here are not watched;
import the file again after changing the palette.
